# PagePort 安装与使用(一页)

把网页、文档、ChatGPT 回答保存成 Markdown / PNG / HTML 文件,全部在本机完成。

## 安装(一次性,约 1 分钟)

1. 解压 `PagePort-v1.0.0-extension.zip`,得到一个文件夹(整个保留)。
2. Chrome 地址栏输入 `chrome://extensions` 回车 → 打开右上角**开发者模式** → 点**加载已解压的扩展程序** → 选择解压出的文件夹。
3. 点工具栏拼图图标 🧩,把「PagePort」📌 固定到工具栏。

## 使用(两步)

1. **点扩展图标**:页面上出现保存面板,鼠标移到哪块内容,哪里就高亮。
2. **点击内容 → 点「保存到本地」**:区域锁定后,面板实时显示将要保存的 Markdown;选好格式(Markdown / PNG 图片 / HTML 快照)保存即可。文件在浏览器下载里,双击就能打开。

快捷键:点击前 **↑** 扩大选区、**↓** 缩小、**Esc** 取消;锁定后同样可调。打开面板前已经选中了一段文字,会直接进入该选区的预览。

## 三种格式怎么选

| 格式 | 适合 | 说明 |
|---|---|---|
| Markdown | 文章、回答、表格、代码、公式 | 纯文本,可放进 Obsidian / Typora 等 |
| PNG 图片 | 图表、卡片、看板等"画面" | 按所选清晰度整块截图 |
| HTML 快照 | 想要"一个文件还原样" | 自包含网页(内嵌画面+来源+时间),离线可开 |

在 ChatGPT 里:点击任意回答,面板显示「对话消息」即表示选中了整条回答(含公式转 LaTeX、表格转 Markdown)。

## 常见问题

- **chrome:// 或应用商店页面点图标没反应?** 这类页面浏览器禁止扩展注入,会自动打开说明页。去任意普通网页再试。
- **粘贴的内容怎么导?** 面板里点「粘贴导入」,按 Ctrl+V,再保存。
- **PNG 文字不够清晰?** ⚙ 设置里把清晰度调到 3×。
- **保存失败?** 面板会显示原因,点「保存到本地」重试或换个区域。

> 本工具只在你点击时读取当前页面的可见内容,不上传任何数据。页面上的脚本、登录态、隐藏内容不会被保存。
