# 产品界面规范 · Decision · v0.5.2 usability

定位：精密、克制、可信的本地界面保存工具。原生 HTML/CSS/JavaScript，不引入 UI 框架、字体下载、动画库或远程执行代码。当前视觉以本文件为单一事实来源；历史 v0.5 审查仅供追溯。

## 方向与依据

[两个概念方向](UI_DESIGN_DIRECTIONS.html)标明概念稿，与真实验收截图分开。A「精密工具」采用系统字体、青绿操作色、墨色正文、明确工作区；B「现代编辑工作台」采用纸色、衬线标题和编号侧栏。选择 A：360px Popup 中更紧凑，控件与浏览器使用习惯衔接，识别度集中在捕获框标记和粘贴操作面，不消耗来源内容面积。B 保留为 Exploration，不进入产品。

Frontend Design 用于产品定位和两个方向；Refactoring UI 用于主次层级、渐进披露和配色；UI/UX Pro Max 用于键盘、状态、触控、对比度检查。其检索结果中的营销页、滚动动画、额外图表库建议不适用于本工具，未采用。Web Design Guidelines 用于最终审查。来源和校验见 [Skills 记录](../tests/evidence/ui-upgrade/skills.json)。

## 用户路径

Popup → **手动粘贴 / 导入文件** → Ctrl+V / 选文件 / 拖放 → 原有隔离净化与校验 → 预览 → 下载。允许页面的捕获作为第二路径：选择页面区域 → 锁定 / 扩缩 → 捕获 → 同一预览。ChatGPT 自动提取 Gate 保持关闭。

Popup 宽360px，20px内边距。小型产品标记 → 任务标题 → 主色导入按钮 → 网页捕获次按钮 → 折叠捕获设置 → 状态 → 简短隐私边界。默认格式与受控契约置于“页面捕获设置”，功能、ID、默认值不变。所有来源契约仍需明确勾选，折叠不意味着自动授权。

Importer 桌面最大1120px，主操作面与260px能力说明侧栏；800px以下单栏，375px两侧16px。粘贴区自动聚焦，说明 Ctrl+V；粘贴后的下一键盘停靠点为唯一的原生文件入口按钮，支持点击、Enter/Space和拖放；原生file input隐藏，保留业务ID与文件过滤。四类输入的能力说明不冒充实际结果，最终仍由预览报告判定。限制和解析宽度默认折叠。等待、解析、取消、失败、完成共用状态区域，aria-live 文本描述具体结果，颜色仅辅助。

## Overlay

自有 Shadow root，样式不影响来源。轻量浮动工具条、青绿选框、主色“捕获并预览”。移动预选、点击锁定、↑扩大父容器、↓返回子区域、Enter捕获、Esc取消均保持。浅/深主题、44px按钮与焦点轮廓。错误和进度就地显示，不移除重试入口；重复注入清理旧实例。

## Preview

标题与能力 → 分组策略/格式 → 下载主按钮 → 状态。桌面来源画布在左，288px检查栏在右；窄屏来源在前，报告在后。隔离frame始终保留来源固定像素尺寸及布局；外层显示默认适应窗口，提供100%与25–200%缩放，以CSS transform改变显示，配套画布占位跟随缩放。100%查看保存像素，超宽时允许画布内部横向滚动；适应窗口按宽度缩小，不拉伸小内容，长内容保留纵向滚动。缩放不改变IR和下载。报告内部限高滚动，组件证据、遗漏、注意事项默认折叠，Interactive要求降级确认时自动展开原因；截图的原/保存尺寸与质量损失始终可见；诊断下载在检查栏下，明确不含正文。

Auto自动恢复安全有限行为；Interactive优先交互，不可恢复组件必须确认静态降级，无可恢复交互则阻止；Static不加载受控运行时。仅HTML/ZIP启用策略，静态格式禁用策略。SVG/PNG按当前实际结构和像素限制提前禁用不可用选项；格式旁说明HTML、ZIP、JSON的主要用途。原生details与有限模型如实显示能力；未知来源不获得来源等价证明。确认、失败恢复、会话过期逻辑不变。

## 内容隔离与已知边界

ui.css 仅扩展页面加载，Overlay 的CSS仅位于自己的Shadow root。渲染器、IR、归档、配方和来源捕获策略不套新主题。导出不增加标记、卡片、页眉或任意宽度。未指定背景的本地HTML默认白色画布，避免系统深色与默认黑字产生冲突；文件自身明确背景仍优先，已有JSON快照不改色。

无新权限、网络请求、CSP放宽、后台剪贴板读取或组件适配器。单纯粘贴仍不授予recipe权限。Windows/Obsidian及完整辅助技术验收不由Linux截图代替。测试、实际截图与剩余边界统一见 [当前可用性审查](USABILITY_REVIEW_0.5.2.md)；历史视觉方向见 [界面升级审查](UI_UPGRADE_AUDIT.md)。
