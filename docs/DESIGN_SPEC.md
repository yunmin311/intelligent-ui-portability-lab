# v0.5.1 产品与交互规范 · Decision

原生 HTML/CSS/JavaScript，无 UI 框架；保持浏览器原生风格、系统字体和既有浅暗令牌。面向有权保存的组件、图表和当前状态；HTML 优先来源视觉，Markdown 面向笔记，JSON 保存版本化结构。导出不套品牌卡片。ChatGPT Gate 继续关闭。

## 用户流程与 Popup

打开允许页面 → Popup 选格式 → 如需有限模型，明确勾选“受控组件契约（仅已知模型）” → 选择区域 → 预览检查 → 下载 → 本地打开。所有网页包含本地 fixture 都需要此开关；默认未勾选。说明明确未知来源不因此获得等价性证明。它与预览页的“确认静态降级”是两种独立确认。

Popup 沿用 348 px 宽、20 px 内边距：标题、组件判定提示、格式、受控契约、主按钮、导入次按钮、状态与隐私说明。主操作只有“选择页面区域”。按钮执行时禁用，状态使用文字；禁止站点和注入失败均给具体反馈。没有未生效设置页。

## Overlay

自有 Shadow root，框选层不改变原页布局；移动预选、点击锁定，↑/↓ 扩缩容器，Enter 捕获，Esc 取消。body 为最大范围，html 不可选。捕获显示进度；重复注入清理旧实例；错误保留选择器供重试。取消为协作取消，不承诺单次浏览器原生调用瞬时中断。

## 预览

标题与能力徽标在上；交互策略和导出格式各自与标签成组；下载文件为唯一主色操作，下载遗漏报告为次操作。375 px 下字段纵向排列、按钮同组，工具栏不横向溢出。来源画布保持固定尺寸，预览容器允许滚动。

报告显示组件总数与能力计数、尺寸与元素数；组件详细证据/原因、差异遗漏、保存范围默认折叠。报告桌面限高 240 px，窄屏限高 200 px，展开后内部滚动，键盘可聚焦报告。全部动态文案使用 textContent，不执行来源内容。

Auto 恢复通过有限模型验证的组件，未知控件静态；Interactive 无可恢复交互则禁止导出，有未知组件须显式确认降级；切格式/策略清除确认。Static 禁止全部行为。仅 HTML/ZIP 启用策略；其他格式静态。当前实捕模型显示 model-validated，原生折叠显示 native-preserved，未知显示 static-fallback。历史 reconstructed-tested 枚举不代表新捕获获得来源等价性。

受控 tabs 支持点击、方向键、Home/End；计算器只做限定加法；布尔开关控制两个面板。模型不是原站事件处理器。失效预览禁用下载；格式不支持时说明原因。下载反馈仅为“已向浏览器发起”，最终完成看浏览器下载列表。

## 手动粘贴 / 导入文件 · Implemented

沿用现有令牌和原生控件：标题与本地处理徽标 → 主粘贴区 → 文件/拖入入口 → 折叠限制及解析宽度 → 状态/取消 → 隐私说明。单栏最大640px，窄屏16px留白；14px正文，17px标题，8/16/24px间隔，不采用独立原型的绿色品牌和双栏导航。粘贴区初始聚焦，Ctrl+V处理一次事件；用户可先点击再粘贴。

按Refactoring UI层级原则：主要任务高于文件备选入口和限制信息；不依赖颜色传递状态，aria-live说明解析/缩放/完成/失败/取消。处理时文件入口禁用，重复粘贴解释等待或取消；取消后不生成预览。未知交互和截图visual-only在既有预览能力报告中说明，不增加无效设置。

手动内容经过同一隔离与格式链路。产品自身布局不写入快照；不添加品牌页眉、卡片或装饰。纯文本只提供必要的保留换行样式，富文本只保留得到的安全结构/样式，截图只保存像素。真实页面截图与窄屏深色截图见当前测试报告；合成样本不是ChatGPT原生UI验收。
