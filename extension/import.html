或导入文件

HTML、SVG、JSON、图片、TXT / Markdown。每次一个文件。

原尺寸模式保存每个像素、不压缩，ZIP 内含完整单图供笔记引用。仅 ZIP 模式上限更高（840 万像素 / 16 MB 输入），但不生成可再次导入的 JSON。

等待粘贴或文件；转换后在预览页选择格式并下载。
文件限制与解析宽度

HTML/SVG ≤ 2 MB，JSON ≤ 4 MB，文本 ≤ 100 万字符。标准图片 ≤ 16 MB / 4000 万像素，缩放至不超过 100 万像素；原尺寸模式 ≤ 840 万像素，超出容量会拒绝。预览会说明实际尺寸与损失。

保存到什么程度？

截图 保存画面
保留画面，按钮与图表不会恢复交互。
富文本 保留结构
尽可能保留标题、表格、代码与安全样式。
纯文本 保存文字
保留文字与换行，不执行其中的 HTML。
导出的 JSON 再次导入
已验证的组件通过校验后恢复有限交互。

你决定保存什么

不会读取来源网页或后台剪贴板。正文、图片中的敏感信息需要你检查。

图片笔记请下载 ZIP，内含 notes.md 和图片资源。未知脚本不会恢复。
